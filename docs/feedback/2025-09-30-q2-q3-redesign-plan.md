# 第2問・第3問リデザイン検討ノート（2025-09-30）

## 背景
- 出典: `docs/feedback/2025-09-23-beta-feedback.md` の指摘（情報過多・CBT乖離・手書き体験不足）。
- 現状: Expoベース v1.0.4。第2問は `LedgerEntryFormWithDropdown.tsx` による汎用フォーム、第3問は `TrialBalanceForm.tsx` の自由入力テーブル。
- 目的: CBT本番に近いUIと行動喚起（手書き・転記感）の両立。

## 現状課題の整理
- **フォーム汎用化の弊害**: 第2問は問題ごとに列構成が異なるが、単一コンポーネントで動的生成しているためUIが冗長・操作量過多。
- **アカウント選択の過多**: `STANDARD_ACCOUNT_OPTIONS`（71件）を全問題で提示、該当科目探索コストが高い。
- **CBT乖離**: 実際のCBTは固定行列＋ドロップダウン選択。現行はスクロール式リスト＋モーダル選択で視覚的に違和感。
- **書き込み感の欠如**: 電卓・メモ領域がなく、学習者の「転記しながら確認」体験が希薄。

## CBT形式・競合調査メモ（ChatGPT知見）
- **日商簿記3級 CBT**: 第2問は2題構成（帳簿/補助簿・伝票）。設問ごとに固定表が提示され、列ヘッダーは「日付/摘要/借方/貸方」等でブランクはドロップダウン＋数値入力。第3問はA4横幅想定の試算表や損益計算書を上下2ペインで提示し、全マスが固定。
- **競合アプリ**: パブロフ簿記、スタディング、CPAラーニングはいずれも CBT 風の固定レイアウトと、設問内限定の選択肢を採用。途中保存（仮解答）と計算メモを併設。復習時にはハイライト付き解説の段階表示が行われる。

## 改修方針（第2問）
1. **テンプレート分割**: `ledger_account` を `general_ledger` / `subsidiary_ledger` / `voucher` の3テンプレに再分類。各テンプレで列構成と入力コンポーネントを固定化。
2. **設問別選択肢**: `question-accounts-mapping` を使用し、問題JSONに `allowed_accounts` を格納。UIはインラインドロップダウン（ActionSheetを廃止）で即選択。
3. **入力ガイド段階表示**: 「①取引確認→②転記→③残高確認」のステップUI。必要時のみ詳細解説を開く折りたたみ表示。
4. **メモペイン**: 右側（タブレット）または下部（モバイル）に「下書きパッド」（数字入力・手書きキャンバス）を設置し、紙に書く体験をエmul。
5. **操作ログ短縮**: 行は最大表示で固定し、使用しない行は非活性グレーアウト（CBT準拠）。

## 改修方針（第3問）
1. **試算表レイアウト刷新**: `TrialBalanceForm` を2ペイン（問題文 / 入力表）に分離し、表は固定幅グリッド＋列合計自動計算表示。借方・貸方合計が常時ヘッダーに固定表示される仕組みに変更。
2. **調整仕訳ハイライト**: 調整仕訳エリアを別セクションに設け、入力と同時に試算表へ転記されるライブフィードバックを追加。
3. **設問バリアント対応**: Q_T_005〜008など8桁精算表向けにカラムセットを事前定義。問題JSONに `layout_variant` を追加し、UIの列数と桁区切りを切替える。
4. **書き込み支援**: 「転記メモ」モードでは、補助計算行を追加表示し実施中の差額をメモできる。E2Eでは Detox で残高一致チェックを自動化。
5. **正答比較UI**: 解説時はCBT風に正答欄へ淡色で表示し、ユーザー入力との差異を色で強調。

## 共通UX改善
- CBTライクなヘッダー（タイマー・設問ナビ・マーク/戻るボタン）をセクション共通化。
- `AnswerGuide` の文量を3レベル（概要→詳細→補足）で折りたたみ、初期表示は概要のみ。
- スマホ縦持ちでは `ScrollView` 依存を減らし、セクション内タブ（入力/メモ/解説）で切替。タブ間の状態は保持。
- 配色: CBT標準に合わせたホワイト/ブルーのコントラストスキームを `theme` に追加。
