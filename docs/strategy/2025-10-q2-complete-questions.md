## 概要とデータ構造

### 第二問の目的

簿記3級試験の第二問は、**帳簿記入**を中心とした問題です。従来の「ゼロから帳簿を作成する形式」（Q_L_001-040）は時間がかかりすぎる（10-15分/問）ため廃止し、**穴埋め形式（2-3箇所）**で全70問を新規作成しました。

### 設計原則

1. **穴埋め2-3箇所の厳守**: すべての問題で一貫
2. **選択式優先**: 数値入力ではなくボタン/ドロップダウン選択
3. **時間削減**: 1-3分/問（従来10-15分から80-90%削減）
4. **完了率向上**: 70%+を目標（従来30%から大幅改善）
5. **スマホ最適化**: 大きなボタン、明確なフィードバック

                      | 4/30 次月繰越 60,000
```

**ヒント**:

- 4/1: 前月から繰り越された現金は50,000円です
- 4/3: 商品を現金で売り上げました（金額不明）
- 4/5: 商品を現金25,000円で仕入れました
- 4/10: 給料15,000円を現金で支払いました

**問題文**:

**支払手形勘定**:

9/31 次月繰越  (②)     | 9/15 買掛金    120,000
```

**ヒント**:

- 9/1: 前月から繰り越された支払手形の残高は200,000円です
- 9/10: 支払手形の期日決済で当座預金から引き落としました（金額不明）
- 9/15: 買掛金の支払いとして約束手形を120,000円振り出しました
- 9/31: 次月に繰り越す支払手形の残高（金額不明）
- 借方合計と貸方合計は必ず一致します

**選択肢**:

- ①: A. 80,000円 B. 90,000円 C. 100,000円 D. 110,000円
- ②: A. 210,000円 B. 220,000円 C. 230,000円 D. 240,000円

**正解**:

- ① **B. 90,000円**
- ② **C. 230,000円**

**計算過程**:

1. 借方合計 = ① + ②
2. 貸方合計 = 200,000 + 120,000 = 320,000

6. 理論確認: 支払手形の残高は前月繰越200,000 + 新規振出120,000 - 期日決済90,000 = 230,000

  correctAnswers: { transactionIndex: number; bookIds: string[] }[],
): boolean {
  return userSelections.every((userSelection, index) => {
    const correctAnswer = correctAnswers[index];
    if (userSelection.transactionIndex !== correctAnswer.transactionIndex)
      return false;

4. **三分法の理解**: 簿記3級では三分法（仕入・売上・商品の3勘定を使用）が標準的です。商品の仕入時は「仕入」勘定、売上時は「売上」勘定を使用し、期末に「商品」勘定で調整します。

5. **返品の影響**: 返品は元の取引の逆仕訳となります。仕入返品は買掛金と仕入の減少、売上返品は売上と売掛金の減少となります。
