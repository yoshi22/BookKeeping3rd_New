# 第2問・第3問の戦略的ポジショニング：「スマート・フォーカス」アプローチ

**作成日**: 2025年10月1日
**対象期間**: 2025年10月～2026年3月
**ステータス**: 提案・検討中

## エグゼクティブサマリー

競合アプリの実装状況と市場動向を踏まえ、第2問・第3問を従来の「均等実装」から **「戦略的差別化ツール」** として再定義する。第1問（仕訳）への集中投資により学習効率を最大化しつつ、第2問・第3問を「理解度確認」機能として活用することで、競合との明確な差別化を図る。

### 核心戦略

- **第1問特化**: 252問の品質向上と学習体験の極限最適化
- **第2問・第3問リポジショニング**: 「おまけ」から「学習効率化ツール」へ転換
- **CBT優位性活用**: 既存のCBTインフラを第1問の圧倒的体験向上に集中投下

### 1.1 簿記3級本試験の配点構造

### 1.2 競合アプリの実装パターン分析

#### パターンA: 仕訳問題重視型（市場シェア約70%）

**代表例**: 『仕訳マスター』『簿記3級 仕訳問題集』

**特徴**:

- 第1問に90%以上のリソース集中（500-1000問）
- 第2問・第3問は簡易版または実装なし
- 開発・運用コストの最小化

**強み**: 学習効率の高さ、アプリサイズの軽量性
**弱み**: 本試験形式との乖離、差別化の困難

#### パターンB: バランス実装型（市場シェア約20%）

**代表例**: 『簿記3級 完全対策』系アプリ

**特徴**:

- 各問題タイプを均等に実装（150問×3分野）
- UI/UXの複雑化によるユーザビリティ低下
- 開発コストの増大

**強み**: 網羅性の高さ、本試験準拠感
**弱み**: 各機能の完成度不足、操作の複雑さ

#### パターンC: 本試験準拠型（市場シェア約10%）

**代表例**: 『CBT完全再現』系プレミアムアプリ

**特徴**:

- CBT形式の忠実再現

- 企業研修・学校向け

**強み**: 完全な本試験対応
**弱み**: 高価格、複雑すぎる操作性

## 2. 実際の簿記3級CBT試験形式の詳細分析

### 2.1 第二問の出題形式と特徴

#### 問題構成

**配点**: 20点（問1と問2の2問構成）
**出題パターン**: 以下の3つのタイプから2問が選択される

#### タイプA: 語句記入問題

**形式**: 簿記用語の穴埋め文章＋選択肢から選択

**具体例**:

```
問題文: 「期末資本が期首資本を上回る場合、その差額を（ ① ）という」
選択肢: ア. 当期純利益  イ. 当期純損失  ウ. 繰越利益剰余金  エ. 資本金
正答: ア
```

**特徴**:

- 簿記の基本概念・用語の理解を確認
- 問題文は1-2文程度の短文
- 選択肢は4-6個程度
- 1問あたり2-5個の穴埋め（合計10点）

**CBT操作方法**:

- ドロップダウンメニューまたはラジオボタンで選択
- 操作時間: 30秒-1分/問

#### タイプB: 補助簿選択問題

**形式**: 取引文＋該当する補助簿を複数選択

**具体例**:

```
問題文: 「商品を掛けで仕入れ、一部を現金で支払い、残りは買掛金とした」
該当する補助簿:
□ 現金出納帳         → ○ (現金支払あり)
□ 当座預金出納帳     → × (当座預金使用なし)
□ 仕入帳            → ○ (商品仕入あり)
□ 売上帳            → × (売上なし)
□ 商品有高帳         → ○ (商品増加あり)
□ 買掛金元帳         → ○ (買掛金発生あり)
□ 売掛金元帳         → × (売掛金なし)
□ 支払手形記入帳     → × (手形なし)
□ 受取手形記入帳     → × (手形なし)
□ 固定資産台帳       → × (固定資産なし)

正答: 現金出納帳、仕入帳、商品有高帳、買掛金元帳（4つ選択）
```

**補助簿の種類**（10種類）:

1. 現金出納帳
2. 当座預金出納帳
3. 仕入帳
4. 売上帳
5. 商品有高帳
6. 買掛金元帳
7. 売掛金元帳
8. 支払手形記入帳
9. 受取手形記入帳
10. 固定資産台帳

**特徴**:

- 複数正解が一般的（2-4個）
- 補助簿の役割と取引の関連性を理解する必要
- 1問あたり5取引程度（合計10点）

**CBT操作方法**:

- チェックボックスで複数選択
- 操作時間: 1-2分/問

#### タイプC: 勘定記入問題（現行実装済み）

**形式**: T字勘定への転記問題

**具体例**:

```
現金勘定への記入を行いなさい。

前月繰越: 100,000円

取引:
10/5  商品売上（現金）: 50,000円
10/10 給料支払（現金）: 30,000円
10/15 売掛金回収（現金）: 20,000円
10/20 買掛金支払（現金）: 15,000円

解答欄:
        現金
━━━━━━━━━━━━━━
借方      | 貸方
日付 摘要 金額 | 日付 摘要 金額
10/1 前月繰越 100,000 | 10/10 給料 30,000
10/5 売上 50,000 | 10/20 買掛金 15,000
10/15 売掛金 20,000 |
```

**特徴**:

- 日付、摘要（相手科目）、金額を入力
- 残高計算が必要な場合もある
- 転記の正確性を確認

**CBT操作方法**:

- 日付: テキスト入力またはドロップダウン
- 摘要: 勘定科目ドロップダウン（20-30科目）
- 金額: 数値入力
- 操作時間: 3-5分/問

## 3. スマホアプリ向け新規問題形式設計戦略（穴埋め方式）

### 3.1 基本方針：「穴埋め2-3箇所×短時間完結」

**コンセプト**: 実際の試験の本質的な理解を問いながら、**スマホで2-5分以内に解答できる穴埋め形式**に統一。既存のQ_L_040問、Q_T_012問は**廃止し、スクラッチで新規作成**。

**4つの原則**:

1. **穴埋め箇所の厳格な限定**: 1問あたり**2-3箇所のみ**
2. **既存情報の提供**: 問題に必要な情報の80%を予め表示し、残り20%を穴埋め
3. **選択式優先**: 数値入力よりもドロップダウン選択を優先（操作ミス防止）
4. **時間短縮**: 1問**2-5分以内**で完了可能（現状10-30分を80%以上削減）

### 3.2 第二問の新規問題形式設計（全てスクラッチ作成）

#### タイプA: 語句記入問題（新規実装・優先度：最優先）

**目標**: 簿記用語の基本理解を確認する最軽量問題タイプ

**スマホ最適化設計**:

```typescript
// 問題構造
interface VocabularyQuestion {
  id: string;
  questionText: string;    // 「期末資本が期首資本を上回る場合、その差額を（①）という。これは（②）計算書で算出される。」
  blanks: {
    index: number;         // ①、②の位置
    choices: string[];     // ["当期純利益", "当期純損失", "繰越利益剰余金", "資本金"]
    correctIndex: number;  // 0 (当期純利益)
  }[];
}

// UI要素
- 問題文: 大きな文字で表示、穴埋め部分はハイライト
- 選択肢: 4-6個の大きなボタン（タップで選択）
- フィードバック: 即座に正誤表示＋簡潔な解説
```

**実装スペック**:

- 問題数: **30問**（基礎用語の網羅）
- 1問あたりの穴埋め: **2-3箇所**（厳守）
- 解答時間目安: 1-2分/問
- 実装コスト: **低**（選択UIのみ）

**出題内容例**:

1. 会計原則: 「継続企業の前提」「発生主義」「実現主義」
2. 勘定科目: 「現金過不足」「貸倒引当金」「減価償却累計額」
3. 帳簿: 「主要簿と補助簿の区別」「仕訳帳」「総勘定元帳」
4. 決算: 「試算表」「精算表」「財務諸表」

**期待効果**:

- 簿記用語の理解度を短時間で確認
- 第1問（仕訳）の基礎知識を補強
- ゲーム感覚で気軽に学習可能
- 「時間がかかりすぎる」苦情の完全解消

#### タイプB: 補助簿選択問題（新規実装・優先度：高）

**目標**: 取引と帳簿の関連性を理解する実務的問題

**スマホ最適化設計**:

```typescript
// 問題構造
interface AuxiliaryBookQuestion {
  id: string;
  transactions: string[];  // 取引の配列（5取引程度）
  books: {
    name: string;          // "現金出納帳"
    icon: string;          // アイコンで視覚化
  }[];
  correctAnswers: {
    transactionIndex: number;
    bookIndices: number[];  // 複数選択可能
  }[];
}

// UI要素（2つの改善案）
案1: マトリックス表（推奨）
    現金  当座  仕入  売上  商品  買掛  売掛  ...
取引1 ☑️   ☐   ☑️   ☐   ☑️   ☑️   ☐
取引2 ☐   ☑️   ☐   ☑️   ☐   ☐   ☑️
...

案2: 取引ごとの展開式
取引1を選択 → 該当する補助簿を複数選択 → 次の取引へ
```

**発生確率**: 中
