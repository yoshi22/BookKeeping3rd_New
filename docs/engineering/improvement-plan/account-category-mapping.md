# 勘定科目カテゴリマッピング定義書

## 概要

本書では、簿記3級問題集アプリの勘定科目フィルタリング機能において使用する、問題カテゴリと勘定科目の関連付けを定義します。

## カテゴリ定義

### 1. 現金・預金系（cash_deposit）

#### コア勘定科目（必ず含める）
- 現金
- 現金過不足
- 小口現金
- 当座預金
- 普通預金
- 定期預金

#### 関連勘定科目（状況に応じて追加）
- 当座借越
- 雑収入（現金過不足判明時）
- 雑損失（現金過不足判明時）

#### 除外勘定科目
- 商品、仕入、売上などの商品売買系
- 建物、備品などの固定資産系
- 給料、賞与などの人件費系

#### 適用される問題パターン
- 現金実査、現金過不足
- 小口現金の前渡し・補給
- 預金の預入・引出
- 当座借越の処理

---

### 2. 商品売買系（merchandise）

#### コア勘定科目
- 商品
- 仕入
- 売上
- 売掛金
- 買掛金
- 繰越商品

#### 関連勘定科目
- 前払金
- 前受金
- 受取手形（掛け売買の代替）
- 支払手形（掛け仕入の代替）
- 発送費（諸掛り）
- 保管費（諸掛り）
- 現金（即金取引）
- 当座預金（振込取引）

#### 除外勘定科目
- 固定資産系全般
- 給与・人件費系全般
- 決算整理系（繰越商品を除く）

#### 適用される問題パターン
- 商品の仕入・売上
- 掛け取引
- 手付金・内金の処理
- 返品・値引き
- 諸掛りの処理

---

### 3. 固定資産系（fixed_assets）

#### コア勘定科目
- 建物
- 建物減価償却累計額
- 備品
- 備品減価償却累計額
- 車両運搬具
- 車両運搬具減価償却累計額
- 土地
- 機械装置
- 機械装置減価償却累計額

#### 関連勘定科目
- 減価償却費
- 固定資産売却益
- 固定資産売却損
- 固定資産除却損
- 建設仮勘定
- 未払金（固定資産購入時）
- 現金（購入・売却時の決済）
- 当座預金（同上）

#### 除外勘定科目
- 商品売買系全般
- 仕入、売上
- 給料、賞与などの人件費系

#### 適用される問題パターン
- 固定資産の取得
- 減価償却の計上
- 固定資産の売却
- 固定資産の除却
- 資本的支出と収益的支出

---

### 4. 給与・人件費系（payroll）

#### コア勘定科目
- 給料
- 賞与
- 賞与引当金
- 賞与引当金繰入
- 法定福利費

#### 関連勘定科目
- 預り金（源泉所得税、社会保険料）
- 未払給料
- 未払賞与
- 現金（給与支払）
- 当座預金（振込支給）
- 福利厚生費

#### 除外勘定科目
- 商品売買系全般
- 固定資産系全般
- 売上、仕入など営業系

#### 適用される問題パターン
- 給与の支払い
- 源泉徴収
- 社会保険料の処理
- 賞与の支給と引当金
- 退職金の処理

---

### 5. 決算整理系（settlement）

#### コア勘定科目
- 貸倒引当金
- 貸倒引当金繰入
- 貸倒引当金戻入
- 減価償却費
- 各種減価償却累計額
- 前払費用
- 前受収益
- 未払費用
- 未収収益

#### 関連勘定科目
- 売掛金（貸倒引当金の対象）
- 受取手形（同上）
- 保険料（前払費用の例）
- 支払家賃（同上）
- 受取家賃（前受収益の例）
- 支払利息（未払費用の例）
- 受取利息（未収収益の例）

#### 除外勘定科目
- 日常の営業取引系
- 現金、小口現金など

#### 適用される問題パターン
- 貸倒引当金の設定
- 減価償却の計上
- 費用・収益の見越し計上
- 費用・収益の繰延べ
- 棚卸資産の評価

---

### 6. 債権債務系（receivables_payables）

#### コア勘定科目
- 売掛金
- 買掛金
- 受取手形
- 支払手形
- 貸付金
- 借入金

#### 関連勘定科目
- 未収金
- 未払金
- 立替金
- 預り金
- 仮払金
- 仮受金
- 受取利息（貸付金関連）
- 支払利息（借入金関連）
- 手形売却損

#### 除外勘定科目
- 固定資産系全般
- 商品、仕入、売上（取引自体を除く）

#### 適用される問題パターン
- 掛け取引の決済
- 手形の振出・受取
- 手形の割引・裏書
- 金銭の貸借
- 未決済項目の処理

## 対になる勘定科目の定義

以下の勘定科目は、一方が出現した場合、もう一方も選択肢に含めます：

| 勘定科目A | 勘定科目B | 理由 |
|-----------|-----------|------|
| 売掛金 | 買掛金 | 掛け取引の対 |
| 受取手形 | 支払手形 | 手形取引の対 |
| 貸付金 | 借入金 | 金銭貸借の対 |
| 前払金 | 前受金 | 手付金の対 |
| 前払費用 | 前受収益 | 経過勘定の対 |
| 未収収益 | 未払費用 | 経過勘定の対 |
| 受取利息 | 支払利息 | 利息の対 |
| 受取手数料 | 支払手数料 | 手数料の対 |
| 仮払金 | 仮受金 | 仮勘定の対 |
| 立替金 | 預り金 | 一時的な金銭の対 |

## 類似勘定科目の定義

学習効果のため、以下の類似科目は誤答選択肢として追加を検討：

| 正答科目 | 類似科目 | 混同しやすい理由 |
|----------|----------|------------------|
| 消耗品費 | 消耗品 | 費用と資産の混同 |
| 前払金 | 前払費用 | 前払いの性質の違い |
| 未払金 | 未払費用 | 未払いの性質の違い |
| 受取手形 | 売掛金 | 信用取引の形態 |
| 支払手形 | 買掛金 | 信用取引の形態 |
| 備品 | 消耗品 | 資産の分類 |
| 修繕費 | 修繕引当金繰入 | 修繕関連の処理 |

## カテゴリ判定ルール

### 優先順位

1. 正答科目から判定
2. 問題文のキーワードから判定
3. tags_jsonのsubcategoryから判定
4. デフォルトカテゴリ（other）

### キーワードマッチング

| キーワード | 判定カテゴリ |
|------------|--------------|
| 現金、小口、実査 | cash_deposit |
| 商品、仕入、売上、売買 | merchandise |
| 建物、備品、車両、減価償却 | fixed_assets |
| 給料、賞与、源泉 | payroll |
| 決算、整理、引当、繰延、見越 | settlement |
| 手形、掛け、貸付、借入 | receivables_payables |

## 成功指標

- 各カテゴリで正答科目が必ず含まれる: 100%
- 表示される科目が論理的に関連している: 95%以上
- ユーザーが違和感を感じない: 満足度4.0/5.0以上

## 注意事項

### 関連性の判断基準

勘定科目の関連性は以下の観点で判断：

1. **取引の流れ**: 同じ取引で連続して使われる可能性
2. **会計処理の選択肢**: 同じ経済事象の異なる処理方法
3. **学習効果**: 対比して覚えるべき科目
4. **実務での関連**: 実務で同時に検討される科目

### 除外の判断基準

以下の場合は積極的に除外：

1. 全く異なる取引領域の科目
2. 頻出であっても論理的関連がない科目
3. 初学者を混乱させる高度な科目（該当問題を除く）
