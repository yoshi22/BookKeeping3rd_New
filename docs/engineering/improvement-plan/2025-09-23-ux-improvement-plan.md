# UX改善計画書

## エグゼクティブサマリー

### 主要な問題点
1. **情報過多**: UI全体で文字が多く、直感的な操作が困難
2. **勘定科目選択の困難さ**: 71個の選択肢から選ぶ必要があり、無関係な科目が大量表示
3. **視覚的フィードバック不足**: 統計が数字のみで、モチベーション維持が困難
4. **アプリの位置づけ不明確**: ターゲットユーザーとコアバリューが不明瞭

### 解決方針
- **Phase 1**: UIのシンプル化と操作性改善（Quick Win）
- **Phase 2**: アプリの再定義と視覚化強化（Core Value）
- **Phase 3**: 長期的な学習体験向上（Future Enhancement）

## 現状分析

### アプリケーション構成

#### 問題データベース
- **総問題数**: 302問
- **問題タイプ別内訳**:

  試算表問題 (trial_balance): 8問 (2.6%)
  その他: 6問 (2.0%)

#### 勘定科目システム
- **実装済み勘定科目数**: 71個
- **実装ファイル**: `src/components/shared/AccountOptions.ts`
- **選択UI**: `UnifiedAccountSelector.tsx`

  - 全問題で同じ71個の選択肢が表示
  - 問題と無関係な科目が多数含まれる

#### UI/UXの現状
- **画面構成**:
  - タブナビゲーション: ホーム、学習、復習、設定
  - 問題解答画面: 複雑な入力フォーム
  - 統計表示: テキストと数値のみ

- **技術スタック**:
  - React Native + Expo
  - TypeScript (strict mode)
  - SQLite (ローカルDB)
  - Expo Router (ファイルベースルーティング)

### ユーザーフィードバックの分析

#### 定量的な問題
- 勘定科目選択時間: 推定10-15秒/回（71個からの選択）
- 解説読了率: 低い（詳細すぎる内容）
- 学習継続率: 視覚的フィードバック不足により低下

#### 定性的な問題
- 初見での使いづらさ
- 学習モチベーションの維持困難
- CBT本番との乖離

## まとめ

本改善計画は、ベータテスターからの貴重なフィードバックに基づき、簿記3級学習アプリの根本的なUX改善を目指すものです。Phase 1での即効性ある改善から始め、Phase 2でコアバリューの確立、Phase 3で長期的な差別化を実現します。

特に重要なのは、「第1問（仕訳）特化型アプリ」としての明確なポジショニングと、シンプルで直感的なUIの実現です。これにより、ユーザーが本当に求める価値を提供できるアプリへと進化させます。
