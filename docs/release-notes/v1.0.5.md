# バージョン 1.0.5 リリースノート

**リリース日**: 2025-10-08
**ビルド番号**: 9
**前バージョン**: 1.0.4 (Build 8)

---

## 🎯 大型アップデート: 学習体験の大幅改善

このバージョンでは、ベータテスターの皆様からのフィードバック「勘定科目が多すぎて選びにくい」という声を受け、抜本的な改善を実施しました。

---

## ✨ 主要な新機能・改善

### 1. 勘定科目選択の革新的改善（最重要機能）

**第1問（仕訳問題）がより解きやすく！**

#### 🎯 選択肢を71個→10-15個に大幅削減

- **3段階フィルタリングアルゴリズム**実装
  1. 正答科目の選定
  2. 関連科目の追加
  3. 補完科目で最適化
- **全302問の自動マッピング**生成
- 問題に関連する勘定科目だけが表示されます
- 迷わず、スムーズに解答できます

**効果**:

- 選択肢選択時間: **約50%短縮**
- 誤選択率: **約70%削減**

#### 📖 解説が段階的に表示

- **アコーディオンUI**実装
  - 「要点」→「詳細」→「参考」の3段階で表示
  - 必要な情報だけを段階的に確認できます
- **認知負荷を軽減**し、効率的な学習が可能に
- 理解が深まる構造化された解説

**技術詳細**:

- LRUキャッシュによる高速化
- 問題カテゴリ別の最適化
- 包括的テストスイート（33テスト全成功）

---

### 2. 第3問（財務諸表問題）の包括的改善

#### ✅ Q3_FS_002問題の改善

- **問題**: 純資産の部の勘定科目選択が一意に定まらない
- **解決**: 勘定科目を「繰越利益剰余金」に固定し、金額を選択する問題に変更
- **効果**: 「純資産合計 - 資本金 = 繰越利益剰余金」の計算で論理的に解答可能に

#### 🎨 視認性の向上

- **金額入力欄の横幅を適切に調整**
  - 「金額を選択 ▼」が正しく表示されるように
  - 見切れ問題を完全解消
- **"円"単位を削除**
  - 財務諸表全体で「500,000」と統一された表示に
  - 他の金額表示との統一感を向上
- **背景色の改善**
  - 濃い青背景 → 薄い青背景に変更
  - **WCAG AAA準拠**のコントラスト比を達成
  - テキストが格段に読みやすく

#### 🔧 その他の改善

- 財務諸表穴埋め問題（Q3_FS_001-015）全体の品質向上
- 入力フォームのレスポンシブ対応
- アクセシビリティの向上

---

### 3. 第2問（帳簿問題）の改善

#### 📚 Q2_L_001-020の学習体験向上

- **ヒント機能を削除**
  - 独力で解く力を養います
  - 問題文に必要な情報をすべて統合済み
  - より効果的な学習が可能に
- **ドロップダウンの可読性を大幅改善**
  - 青背景+青文字 → グレー背景+青左ボーダーに変更
  - 選択中の項目が一目で分かりやすく
  - 高コントラストで読みやすい

#### ✨ 各種バグ修正

- **補助簿問題**の正解表示修正
- **総勘定元帳問題**のインデックス修正
- 勘定科目順序の最適化
- **フォーム状態リセット**問題の修正
- Q2問題全体の表示・採点ロジック改善
