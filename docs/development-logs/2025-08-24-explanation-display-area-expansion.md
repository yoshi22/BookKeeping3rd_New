# 解説表示領域拡張修正完了 - 2025-08-24

## 修正概要

解答結果ダイアログ内の解説表示領域が狭く、「次の問題へ」ボタンの上まで解説内容が表示されない問題を修正しました。

## 問題の詳細

- **症状**: 解説のスクロール可能領域が画面高さの45%に制限され、利用可能な全領域を活用できていない
- **影響範囲**: `AnswerResultDialog`でQ_J_007などの問題解答時に表示される解説エリア
- **ユーザー要望**: 解説領域を「次の問題へ」ボタンの直上まで拡張したい

## 技術的な解決アプローチ

### 問題の根本原因

1. **固定高さ制限**: `maxHeight`が画面高さの45%に固定されていた
2. **親コンテナとの不整合**: `AnswerResultDialog`の`ScrollView`が`flex: 1`で全領域を使用可能なのに対し、`UnifiedExplanation`が制限されていた
3. **レスポンシブ設計の不備**: 画面サイズやコンテンツ量に関わらず固定比率で制限

### 解決策の設計思想

1. **親コンテナ準拠**: `flex: 1`により親の`ScrollView`コンテナの利用可能領域を最大限活用
2. **自動レイアウト**: React Nativeのflexboxレイアウトに委ねることで、ヘッダーとボタン間の領域を自動計算
3. **コンテンツ優先**: 解説内容の表示を最優先し、利用可能な全領域を活用
