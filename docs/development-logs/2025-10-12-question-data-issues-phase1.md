### 2. テンプレート誤記: credit_account:0（Critical）

**影響度**: 🔴 High
**対象問題数**: 3問

#### 問題内容

`answer_template_json`に以下のtypoが存在：


このtypoにより、テンプレート解析時にエラーが発生する可能性がある。

### 3. 勘定科目配列不完全（Medium）

**影響度**: 🟡 Medium
**確認済み対象**: 1問（全20問の複合仕訳問題で検証が必要）

#### 問題内容

複合仕訳の問題において、`correct_answer_json`に含まれる勘定科目が、`tags_json`の`accounts`配列に完全に反映されていない。

動的フィルタリングシステム（2025-09-24実装）では、`accounts`配列をもとに選択肢を絞り込むため、必要な勘定科目が欠けている場合、ユーザーが正解を入力できなくなる。

#### 確認済みの問題

**Q_J_027** (行434):

```typescript
// 正解に必要な勘定科目
correct_answer_json: 借方「買掛金」、貸方「当座預金」「受取手数料」

// tags_jsonのaccounts（受取手数料が欠落）
tags_json: '{"accounts":["買掛金","当座預金"],...}'
```

#### 影響

- 動的フィルタリングで「受取手数料」が選択肢に表示されない
- ユーザーが正解を入力できない
- 問題の難易度が不当に上昇

#### 対応方針

Phase 2で分析スクリプトを作成し、全20問の複合仕訳問題について以下を検証：

- `correct_answer_json`から必要な勘定科目を抽出
- `tags_json`の`accounts`配列と比較
- 不足・余剰がある問題をリストアップ

## 技術的詳細

### 複合仕訳テンプレートの正しい形式

```typescript
// 単純仕訳（1つの借方エントリ、1つの貸方エントリ）
{
  "type": "journal_entry",
  "journalEntry": {
    "debit_account": "",
    "debit_amount": 0,
    "credit_account": "",
    "credit_amount": 0
  }
}

// 複合仕訳（複数のエントリを配列で表現）
{
  "type": "journal_entry",
  "journalEntry": [
    {"debit_account": "", "debit_amount": 0, "credit_account": "", "credit_amount": 0},
    {"debit_account": "", "debit_amount": 0, "credit_account": "", "credit_amount": 0},
    {"debit_account": "", "debit_amount": 0, "credit_account": "", "credit_amount": 0}
  ]
}
```

### 動的フィルタリングシステムとの関係

2025-09-24に実装された動的勘定科目フィルタリングシステムは、以下のアルゴリズムで選択肢を絞り込む：

1. **正答科目**: `correct_answer_json`から勘定科目を抽出
2. **関連科目**: `tags_json`の`accounts`配列から取得
3. **補完科目**: カテゴリ体系から追加

ただし、ステップ2で`accounts`配列が不完全な場合、ユーザーが正解に必要な科目を選択できなくなる可能性がある。
