# 第3問（財務諸表問題）金額入力欄の横幅修正

## 日時

2025-10-06

## 問題の背景

### 報告された問題

ユーザーフィードバックにより、第3問（Q3_FS問題）の金額入力欄の横幅が極端に狭く、金額が表示されないという問題が報告されました。

### 症状

- **表示**: 「繰越利益剰余金」などの項目の横に、極端に小さな青い四角のみが表示される
- **問題点**: 金額選択ドロップダウンのテキスト（「金額を選択」）が表示されない
- **影響範囲**: Q3_FS問題（財務諸表穴埋め問題）およびQ3_TB問題（試算表穴埋め問題）の金額入力欄すべて

## 原因分析

### 技術的原因

**ファイル**: `src/components/cbt/FillInFinancialStatementForm.tsx`

**問題のコード** (Line 371-373):

```typescript
amountBlankButton: {
  minHeight: 40,
  // minWidthの指定がない
},
```

### 根本原因

1. **幅の指定なし**: `amountBlankButton` スタイルに幅（`minWidth`）の指定がなかった
2. **Flexレイアウトの影響**: BlankSelectorコンポーネントは `flex: 1` のコンテナを持つが、ボタン自体に最小幅が設定されていないため、極端に縮小される
3. **金額表示の要件**: 金額選択肢（例: "500,000円"）を表示するには最低120px程度の幅が必要

## 修正内容

### コード変更

**ファイル**: `src/components/cbt/FillInFinancialStatementForm.tsx` (Line 371-374)

**修正前**:

```typescript
amountBlankButton: {
  minHeight: 40,
},
```

**修正後**:

```typescript
amountBlankButton: {
  minHeight: 40,
  minWidth: 120, // 金額表示に必要な最小幅を確保
},
```

### 修正理由

- **金額の可読性**: 「金額を選択 ▼」のテキストおよび選択済み金額（例: "500,000円"）を表示するには最低120pxの幅が必要
- **ユーザビリティ**: タップ可能な領域が極端に小さいと操作性が悪い
- **視認性**: 金額選択ボタンであることが明確に視認できる必要がある

## 検証結果

### シミュレーターでの確認

**問題**: Q3_FS_002（貸借対照表穴埋め問題）

#### 修正前

- 「繰越利益剰余金」の横: 極端に小さな青い四角のみ表示
- テキスト「金額を選択」が表示されない
- ユーザーが何を操作すべきか不明

#### 修正後（確認済み）

✅ 「繰越利益剰余金」の横: 「金額を選択 ▼」が適切な幅で表示
✅ 「未払金」の横: 「金額を選択 ▼」が読みやすく表示
✅ 選択済み金額も適切に表示される想定（例: "500,000円"）
✅ タップ可能な領域が十分に確保されている

### 視覚的改善

```
修正前:
繰越利益剰余金  [■]  ← 極端に小さい

修正後:
繰越利益剰余金  [金額を選択 ▼]  ← 読みやすい幅
```

## 影響範囲

### 改善される画面

1. **Q3_FS問題（001-015）**: 財務諸表穴埋め問題の金額入力欄すべて
   - 損益計算書の金額入力
   - 貸借対照表の金額入力

2. **Q3_TB問題**: 試算表穴埋め問題で同じ `amountBlankButton` スタイルを使用している場合も改善

### 副作用

**なし**: 最小幅の追加のみなので、既存の表示に悪影響はない

## 技術的詳細

### スタイル適用の流れ

1. `FillInFinancialStatementForm.tsx` で金額空欄を検出
2. `BlankSelector` コンポーネントに `buttonStyle={styles.amountBlankButton}` を渡す
3. BlankSelectorの基本スタイルに `amountBlankButton` スタイルがマージされる
4. `minWidth: 120` により、ボタンの最小幅が保証される

### 関連コンポーネント

- **FillInFinancialStatementForm.tsx**: 財務諸表穴埋め問題のフォーム（修正対象）
- **BlankSelector.tsx**: 選択肢セレクターの共通コンポーネント（変更なし）
- **FillInTrialBalanceForm.tsx**: 試算表穴埋め問題のフォーム（同様の問題がある可能性）
