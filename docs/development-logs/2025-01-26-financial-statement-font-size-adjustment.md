# Q3_FS_015 財務諸表フォントサイズ調整ログ

**日時**: 2025年1月26日 23:28

## 問題

Q3_FS_015（損益計算書と貸借対照表の統合問題）で、一部の項目名が2行で表示されていました。

### 2行表示になっていた項目

**損益計算書:**

- 「販売費及び一般管理費合計」

**貸借対照表:**

- 「建物減価償却累計額」
- 「備品減価償却累計額」
- 「流動資産合計」
- 「固定資産合計」
- 「流動負債合計」
- 「固定負債合計」
- 「繰越利益剰余金」
- 「純資産合計」

## 原因

FillInFinancialStatementForm.tsxのlabelTextスタイルのフォントサイズが大きすぎて、長い項目名（10文字以上）が画面幅に収まらず、2行に折り返されていました。

## 修正内容

### ファイル

- `src/components/cbt/FillInFinancialStatementForm.tsx`

### 変更内容

項目名（ラベル）のフォントサイズを縮小：

```typescript
// 修正前
labelText: {
  fontSize: 15,
  color: theme.colors.text,
  lineHeight: 20,
},
labelTextBold: {
  fontWeight: "bold",
  fontSize: 16,
  color: theme.colors.text,
},

// 修正後
labelText: {
  fontSize: 13,
  color: theme.colors.text,
  lineHeight: 18,
},
labelTextBold: {
  fontWeight: "bold",
  fontSize: 14,
  color: theme.colors.text,
},
```

**変更点:**

- 通常の項目名: `fontSize: 15` → `fontSize: 13` (2px縮小)
- 太字の項目名: `fontSize: 16` → `fontSize: 14` (2px縮小)
- 行間: `lineHeight: 20` → `lineHeight: 18` (2px縮小)

## 結論

フォントサイズを2px縮小することで、最長12文字の項目名（「販売費及び一般管理費合計」「建物減価償却累計額」など）が1行に収まるようになり、ユーザビリティが向上しました。

可読性は維持されており、問題なく利用できることを確認しました。
