# テキストフォーマット修正ログ

**日時**: 2025-08-17  
**実施者**: Claude Code  
**タスク**: 第二問・第三問のテキスト表示問題修正

## 問題の詳細

### 1. 第二問（帳簿問題）

- **症状**: 問題文に「年10月」「年1月」など、年号が欠落した不自然な日本語表記
- **原因**: 数値簡略化処理時に年号部分が誤って削除された
- **影響範囲**: 帳簿問題（ledger）全40問中34箇所

### 2. 第三問（試算表問題）

- **症状**: 問題プレビューに改行コード「\n」がそのまま表示される
- **原因**: エスケープシーケンス「\\n」が実際の改行文字に変換されていない
- **影響範囲**: 試算表問題（trial_balance）全12問中196箇所

## 実施した修正

### 修正スクリプト

`scripts/fix-text-formatting.js` を作成・実行

### 修正内容

1. **年月表記の修正**
   - パターン: `/年([0-9１-９]+月)/g`
   - 修正: 「年10月」→「10月」、「年1月」→「1月」など
   - 修正箇所数: 34箇所

2. **改行コードの修正**
   - パターン: `/\\\\n/g`
   - 修正: 「\\n」（エスケープされた改行）→「\n」（実際の改行）
   - 修正箇所数: 196箇所

### データベース更新

- データバージョン: `"2025-08-17-text-format-fixed"`
- 更新方法: `forceUpdate` フラグを一時的に `true` に設定
