## 問題の詳細

### 修正前の状況

- **問題**: 多くの仕訳問題が「小口現金係に[金額]円を前渡しした」のように、金額だけ変えた同一パターンの重複
- **影響**: 学習者にとって単調で、簿記の多様なパターンを学習できない
- **具体例**:
  - Q_J_002: "小口現金係に500円を前渡しした"
  - Q_J_006: "小口現金係に250円を前渡しした"（金額違いの重複）

### problemsStrategy.mdに基づく設計指針

```
カテゴリー1: 現金・預金取引（42問）

├── 当座預金パターン（15問）

```

### 2. 具体的な修正内容 ✅

#### Q_J_002の修正

**修正前**:

```
問題文: "小口現金係に500円を前渡しした。"
仕訳: 小口現金 500 / 現金 500
```

**修正後**:

```
問題文: "小口現金係への前渡金500円の精算を受け、不足額300円を補給した。"
仕訳: 小口現金 300 / 現金 300
```

#### Q_J_003の修正

**修正前**:

```
問題文: "売掛金500円が当座預金口座に振り込まれた。"
仕訳: 当座預金 500 / 売掛金 500
```

**修正後**:

```
問題文: "現金実査の結果、現金の実際有高が1,200円であったが、帳簿残高は1,000円であった。"
仕訳: 現金 200 / 現金過不足 200
```
