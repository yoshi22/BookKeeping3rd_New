# Q2_L_001-020 ドロップダウン選択スタイルの可読性改善

**日付**: 2025-10-07
**作業者**: Claude Code
**作業時間**: 約30分

## 概要

Q2_L_001-020（勘定記入問題20問）のドロップダウン選択モーダルにおいて、選択状態の視覚表現を改善。青色背景による可読性の問題を、薄いグレー背景と青色左ボーダーアクセントの組み合わせに変更し、視認性を大幅に向上させた。

## 背景

### 問題

- ドロップダウン選択モーダルで選択された項目が青色背景（`rgba(0, 122, 255, 0.1)`）+ 青色テキストで表示
- 青色背景と青色テキストの組み合わせにより、コントラストが不十分で読みづらい
- ユーザーからの改善要望: 「プルダウンが青く編みかけされており、見づらくなっている」

### 既存の実装（変更前）

```typescript
optionItemSelected: {
  backgroundColor: theme.colors.primaryLight || "rgba(0, 122, 255, 0.1)", // 青色背景
},
optionTextSelected: {
  color: theme.colors.primary, // 青色テキスト
  fontWeight: "600",
},
```

**問題点**:

- 青色背景 + 青色テキスト = コントラスト不足
- 視認性が悪く、特に選択肢が多い場合に選択状態が不明瞭
- アクセシビリティ（a11y）の観点からも改善が必要

## 実施内容

### 設計方針

選択状態の視覚表現を以下の方針で改善：

1. **背景色の変更**: 青色 → 薄いグレー（`rgba(0, 0, 0, 0.05)`）
2. **左ボーダーアクセント追加**: 4pxの青色左ボーダーで選択状態を明確化
3. **テキスト色の変更**: 青色 → 通常のテキスト色（黒）
4. **太字は維持**: `fontWeight: "600"` で選択状態の強調を継続

### 修正内容

**ファイル**: `src/components/FillInLedgerForm.tsx` (lines 541-554)

**変更後のコード**:

```typescript
optionItemSelected: {
  backgroundColor: "rgba(0, 0, 0, 0.05)", // 薄いグレー背景
  borderLeftWidth: 4, // 左側にアクセントボーダー
  borderLeftColor: theme.colors.primary, // 青色ボーダーで選択状態を明確に
},
optionText: {
  fontSize: 18,
  color: theme.colors.text,
  textAlign: "center",
},
optionTextSelected: {
  color: theme.colors.text, // 通常のテキスト色（読みやすさ優先）
  fontWeight: "600", // 太字は維持
},
```

### デザイン原則

**コントラスト向上**:

- 背景とテキストの明度差を最大化
- 青色は左ボーダーのみに使用し、テキストは黒で可読性を確保

**視覚的階層**:

- 左ボーダー（4px青色）: 主要な選択インジケーター
- 背景色（薄いグレー）: 副次的な視覚的分離
- 太字テキスト: 追加の強調

**アクセシビリティ**:

- WCAG 2.1 AAレベル準拠を目指したコントラスト比
- 色覚異常のあるユーザーも識別可能（複数の視覚手がかり）

## ユーザビリティ改善効果

### 改善前の問題点

1. **低コントラスト**: 青色背景 + 青色テキスト
2. **可読性低下**: 特に長時間の学習で目が疲れる
3. **選択状態の不明瞭**: 選択肢が多い場合に識別困難

### 改善後の効果

1. **高コントラスト**: グレー背景 + 黒テキスト
2. **可読性向上**: 長時間学習でも目が疲れにくい
3. **選択状態の明確化**: 青色左ボーダーで一目で識別可能
4. **アクセシビリティ向上**: 色覚異常のユーザーも利用しやすい

### ビフォー・アフター比較

**変更前**:

```
[青色背景・青色テキスト] 85,000円
```

- コントラスト不足
- 読みにくい

**変更後**:

```
[青4px|薄灰色背景・黒テキスト(太字)] 85,000円
```

- 高コントラスト
- 明確な選択インジケーター
- 優れた可読性

## 教訓

1. **色の組み合わせ**: 同系色（青+青）の組み合わせは避け、コントラストを優先
2. **複数の視覚手がかり**: 色だけでなく、ボーダー・太字など複数要素で状態を表現
3. **アクセシビリティ優先**: WCAG準拠を意識した設計
4. **段階的改善**: 既存のカスタム実装を活かしながら、スタイルのみで改善可能
