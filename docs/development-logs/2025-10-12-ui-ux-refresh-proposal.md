# UI/UX刷新検討メモ - 2025-10-12

- 実施者: Codex CLI
- 対象: 現行アプリ（簿記3級「復習マスター」）のUI/UX
- 目的: 最新トレンド/競合調査をもとに、全面的なUIリフレッシュ案を整理する

## 1. 現状観察（コード/ワイヤー参照ベース）

- **カラー/ブランド**
  - Primaryは `#2196F3` 系のブルー、Secondaryはグリーン（`#4CAF50`）でややビビッド。
  - ブランドカラー定義が豊富だが、画面ではブルーとグリーンが強く主張し、ニュートラルの使い分けが弱い。
  - 暗色モード対応はあり。ただし高コントラストモードはほぼモノクロ化し、ブランド感が希薄。

- **レイアウト/コンポーネント**
  - 8ptグリッドを意識したシンプルレイアウト。フォーム画面は上下スクロール中心で、カード/セクション境界が薄い。
  - CTAボタン（「解答確定」など）が長方形塗りつぶしのみで、視覚的階層が弱い。
  - ホームの情報カードやタブバーなど、要素に余白がやや少なく、呼吸感が足りない。

- **アイコン/イラスト**
  - `assets/icon.png` など最小限。画面内のアイコンは主にEmojiベース（ワイヤー参照）で統一感に欠ける可能性。
  - ゲーミフィケーション要素（バッジ/ポイントなど）の視覚化が計画レベルで止まっている。

- **タイポグラフィ**
  - `src/theme/typography.ts`ではRoboto系をベースに段階的なスケールを定義。ただし実際の画面でのメリハリは限定的。
  - 特に問題文/解説文など長文に対して行間や余白が少なく、可読性が落ちる懸念。

- **動的フィルタ/フォーム**
  - 統合仕訳フォームは複数行追加が可能でUI自体はモダン。ただし入力コントロールのエッジ/影が少なく、フラットでタッチターゲットが視覚的に分かりにくい。

## 2. 最新トレンド & 競合ベンチマーク（参考）

- **国内資格学習アプリの傾向**
  - Studyplus, スタディング, CPAラーニング等は、淡いニュートラル背景にアクセントカラーをポイント使いする構成。
  - 角丸大きめのカード、シャドウ/レイヤーによる階層表現、Illustration/キャラクターで感情を喚起。
  - ダッシュボード系画面は情報カード化し、1カード=1アクションの設計が主流。

- **汎用モバイルUIトレンド**
  - Material 3 / iOS 17準拠：丸みのあるカード、モーション/フィードバックの強化、Fab/BottomSheetで主要アクションを強調。
  - カラーパレットは「少数アクセント×豊富なニュートラル」。過剰なビビッドは避け、ダークモードでも差分を大きく。
  - アイコンはトーン合わせ（例: Material Symbols Rounded, Phosphor, SF Symbols）、ライン/デュオトーンが流行。
  - マイクロインタラクション（ステート変化やタップエフェクト）でゲーム性を演出。

## 3. 主な課題整理

| 領域 | 現状課題 | ユーザー影響 |
| ---- | -------- | ------------ |
| カラー | ブルー&グリーンが強く単調。情報密度の高い画面で視線誘導が弱い。 | 重要操作が埋もれ、学習導線が分かりにくい |
| レイアウト | 余白・区切りが足りず、ホーム/リストが「文字の壁」になりがち。 | モバイルの瞬間的な把握が難しい |
| タイポグラフィ | 行間と階層が不足。長文の解説が読みづらい。 | 復習効率低下、離脱要因 |
| アイコン/ビジュアル | Emoji混在・アイコンスタイル不統一。モチベーション設計が見えづらい。 | ブランド認知が進まず、学習継続の動機づけが弱い |
| ゲーミフィケーションUI | カラー定義はあるがUIに未反映。進捗/バッジがテキスト中心。 | 達成感が伝わりにくい |

## 4. リフレッシュ方針（提案）

### 4.1 カラーディレクション

- **ベースリセット**: 背景を `neutral.50` 系（#FAFAFA）に統一し、カード/セクションはホワイト＋微シャドウで浮かせる。
- **アクセント減衰**: Primaryブルーは `brandColors.primary[600]` を主CTA（ボタン/リンク）に集中。Secondaryグリーンは達成・正解などのステータス用途に限定。
- **サポートカラー**: 情報状態別にsemanticカラーをバッジ/アイコンのみに使用し、過剰な塗りつぶしを避ける。
- **ダークモード**: ダーク専用の中間グレー（#1E1E1E系）を背景にし、Primaryをやや彩度を落としたブルーへ調整。

### 4.2 レイアウト/コンポーネント

- ホーム/ダッシュボードを「カードグリッド + 水平スワイプ」構成に再設計。
  - 例）「今日のタスク」「復習待ち」「模試スコア」などを独立カード化。
- フォーム系はカード内セクション + sticky CTA（下部固定）で操作を明確化。
- タブバーをアイコン＋テキストのフルカラーから、アイコンベース＋プライマリ色のアクティブインジケータに変更し、視認性とモダンさを両立。

### 4.3 アイコン/イラスト

- `@expo/vector-icons` あるいは `phosphor-react-native` を導入し、Rounded/Outlined系でスタイル統一。
- バッジや学習進捗に軽量イラスト（Blush/Streamlineなど）を採用し、感情的訴求を強化。
- Appアイコン/スプラッシュも余白多め＋ミニマルな簿記モチーフに刷新。

### 4.4 タイポグラフィ/スペーシング

- 見出し階層を `H1(24)`, `H2(20)`, `H3(18)`、ボディを `16/14`、キャプションを `12` で明確化。
- 行間は `lineHeight = fontSize * 1.5` を目安に統一。
- グローバル余白を 8pt グリッドで再設計し、セクション間は 24〜32pt を確保。

### 4.5 ゲーミフィケーションUI

- 進捗サマリにストリーク/ポイント/バッジをカード表示し、カラーリングを `brandColors.gamification` から選択。
- モーダル/トーストで達成感フィードバック（Confetti, Animated checkmark）を追加。

## 5. 競合差別化の方向性

- **「簿記×ゲーミフィケーション×学習心理」の三本柱**
  - 合格への一本道ではなく「簿記業務シミュレーション」の疑似体験としてUIモチーフを設計。
  - 例: 取引入力画面に職場風UI（机/伝票）モチーフ、進捗ダッシュボードを「経理部の業務日報」風に。

- **アクセシビリティ訴求**
  - 高コントラスト・可変フォント・モーション軽減設定をUI設定画面から切替可能にし、公的資格学習アプリとしての安心感を強調。

## 6. 推奨アクションプラン

1. **デザインスプリント（1週）**
   - Figma上でホーム/問題画面/解説画面/ダッシュボードのキーUIをラフ→ハイフィデで作成。
   - カラーパレットのスウォッチ/タイポスケールを定義し、アクセシビリティチェックを通す。

2. **UIライブラリ整備（1〜2週）**
   - `components/ui` に共通カード・ボタン・バッジを再定義。
   - `UnifiedAccountSelector` など既存コンポーネントへトークン適用。

3. **実装フェーズ**
   - ホーム/タブバー → 問題画面 → 解説画面 → 設定/成績の順で段階導入。
   - モーション/マイクロインタラクションは最後にまとめて実装。

4. **ユーザーテスト**
   - 既存ユーザーに対するA/Bテスト or リモートユーザビリティテストを実施し、指標（正答率・滞在時間・復習率）の変化を検証。
