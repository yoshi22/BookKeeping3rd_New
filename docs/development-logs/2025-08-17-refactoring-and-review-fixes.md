## 実施した修正

### 1. 復習リスト自動追加機能の修正

**問題**: 間違えた問題が復習リストに自動追加されず、ユーザーが手動でボタンをクリックする必要があった

**修正内容**:

- `src/services/answer-service.ts` の復習状況更新ロジックを変更
- セッションタイプに関係なく、**不正解時は全て自動的に復習リストに追加**するよう修正
- 学習・復習セッションでは従来通り正解・不正解両方で更新
- 模試など他のセッションでは不正解時のみ復習リストに追加

**変更箇所**:

```typescript
// 変更前: 学習・復習セッションのみ更新
if (request.sessionType === "learning" || request.sessionType === "review") {
  // 復習状況更新
}

// 変更後: 間違えた問題は全セッションで追加
const shouldUpdate =
  request.sessionType === "learning" ||
  request.sessionType === "review" ||
  !isCorrect; // 間違えた問題は全セッションで復習リストに追加
```

### 2. 不要なUIボタンの削除

**問題**: 自動追加機能により「復習リストに追加」ボタンが不要になった

**修正内容**:

- `src/components/AnswerResultDialog.tsx` から「復習リストに追加」ボタンを削除
- 関連するProps（`onReviewQuestion`, `showReviewButton`）も削除
- UIがよりシンプルになり、自動追加機能と矛盾しない設計に変更

### 3. ログシステムの改善

**新規作成**: `src/utils/logger.ts`

- 環境変数による制御（開発/本番）
- ログレベル管理（DEBUG/INFO/WARN/ERROR）
- コンテキスト情報付きロギング
- パフォーマンス測定機能
- ログバッファリング機能

**特徴**:

- 開発環境: DEBUG レベル（詳細ログ）
- 本番環境: WARN レベル（警告・エラーのみ）
- 環境変数 `EXPO_PUBLIC_LOG_LEVEL` で制御可能
