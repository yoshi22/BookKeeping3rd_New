# 2025-10-13 UI Refresh Implementation

## 作業概要
- Figmaデザイン（`docs/design/ホーム.png`）を基に、アプリ全体のトンマナを刷新
- 主要画面（ホーム／学習タブ／復習タブ）のコンポーネント構成・配色・余白を調整
- 絵文字中心のアイコンをプロジェクト標準の `AppIcon` ベクターに統一
- テーマカラーパレットをティール＆コーラル基調の落ち着いたトーンへ更新

## 変更ファイル
- `src/theme/colors.ts`
- `app/(tabs)/_layout.tsx`
- `app/(tabs)/index.tsx`
- `app/(tabs)/learning/index.tsx`
- `app/(tabs)/review/index.tsx`

## 詳細対応
1. **テーマ刷新**
   - ライト／ダーク双方でブランドカラー・セマンティックカラー・グラデーションを再定義
   - 学習状態・カテゴリカラー・アクセシビリティ用フォーカスカラーの統一
2. **タブナビゲーション更新**
   - タブバー背景・ヘッダー配色を新サーフェスカラーに変更
   - `AppIcon` を利用したホーム／学習／復習／設定アイコンに統一
3. **ホーム画面再設計**
   - ヒーローカード＋クイックアクションカード構成へリデザイン
   - カード影／余白／アイコン配置をFigmaのトーンに合わせ調整
4. **学習タブ改善**
   - カテゴリカードや「全問題順次進行」カードを新トンマナに合わせ調整
   - 絵文字アイコンを `AppIcon` に置き換え、カード影と余白を刷新
5. **復習タブ改善**
   - ダッシュボードヘッダー、タブ、CTAカード、分野別カード、統計カードにベクターアイコンと新配色を適用
   - チップやボタン類の背景色・影・余白を整理し、複数セクションでレイアウト統一
