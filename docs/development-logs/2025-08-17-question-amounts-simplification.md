### Phase 2: 統合変換スクリプトの開発

**開発したスクリプト:** `scripts/simplify-amounts-integrated.js`

**主要クラス:** `AmountSimplifier`

**核心機能:**

```javascript
class AmountSimplifier {
  extractAmounts(text)         // テキストから金額抽出
  determineScale(amounts)      // 変換比率決定
  transformText(text, scale)   // テキスト金額変換
  transformAnswerJson(answerJson, scale) // JSON金額変換
  validateQuestion(question)   // 借方・貸方バランス検証
  simplifyQuestion(question)   // 問題統合変換
}
```

**変換アルゴリズム:**

1. 問題文から全金額を抽出
2. 最大額に基づく統一スケール決定
3. 問題文・正答JSON・説明文の同期変換
4. 借方・貸方バランス検証
5. エラー時の自動ロールバック

**スケール決定ロジック:**

- 1,000,000円以上 → 1/1000 (例: 1,500,000円 → 1,500円)
- 100,000-999,999円 → 1/1000 (例: 600,000円 → 600円)
- 10,000-99,999円 → 1/100 (例: 50,000円 → 500円)
- 1,000-9,999円 → 1/10 (例: 5,000円 → 500円)
- 1,000円未満 → 変換なし

validateQuestion(question) {
  const answer = JSON.parse(question.correct_answer_json);
  if (answer.journalEntry) {
    const debit = answer.journalEntry.debit_amount;
    const credit = answer.journalEntry.credit_amount;
    return debit === credit; // 必須条件
  }
}
