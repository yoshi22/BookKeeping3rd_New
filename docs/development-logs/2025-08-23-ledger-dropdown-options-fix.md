# 2025-08-23 第二問（Q_L）ドロップダウン選択肢修正

## 概要

第二問（Q_L001-Q_L040）の帳簿記入問題において、正答勘定科目がドロップダウン選択肢にない問題を発見・修正

## 問題の発見

- ユーザー報告：「第二問について、プルダウンから回答を選択する形式の問題について、正答が選択肢にない場合がある」
- 調査の結果、Q_L問題のドロップダウンオプションリストに重要な勘定科目が不足していることを発見

## 問題の詳細

### 不足していた勘定科目

1. **現金過不足** - Q_L_001の正解データで使用されているが、ドロップダウンに含まれていない
2. **雑損失** - AccountOptions.tsには存在するが、Q_L問題のドロップダウンには含まれていない
3. **雑収入** - AccountOptions.tsには存在するが、Q_L問題のドロップダウンには含まれていない
4. **減価償却費** - 正解データで使用されている可能性があるが、ドロップダウンに含まれていない

### 具体的な例（Q_L_001）

Q_L_001の正解データ：

```json
{
  "entries": [
    {
      "date": "10/28",
      "description": "現金過不足",
      "ref": "",
      "debit": 0,
      "credit": 10,
      "balance": 390
    }
  ]
}
```

しかし、Q_L問題のドロップダウンオプションには「現金過不足」が含まれていなかった。

## 検証方法

## 影響範囲

### 解決された問題

1. **Q_L_001**: 現金過不足の帳簿記入で正答が選択可能
2. **Q_L問題全般**: 必要に応じて雑損失・雑収入・減価償却費が選択可能
3. **CBT形式の完全対応**: 全ての問題で正答がドロップダウンから選択可能

### ユーザーへの影響

- **学習効果の向上**: 正答を選択できないフラストレーションの解消
- **試験対策の完全性**: 実際のCBT形式により近い操作環境の提供
- **既存学習データ**: 影響なし（ドロップダウン選択肢の追加のため）

## 帳簿記入問題の特殊性

### Q_L問題とQ_J問題の違い

- **Q_J問題（仕訳問題）**: UnifiedAccountSelectorコンポーネントのドロップダウンを使用
  - AccountOptions.tsとUnifiedAccountSelector.tsxで管理
  - 前回修正で「雑損失」「雑収入」への統一を実施済み

- **Q_L問題（帳簿記入問題）**: 問題ごとの個別ドロップダウンオプション
  - master-questions.ts内の各問題のanswer_template_jsonで管理
  - 今回修正で必要な勘定科目を追加
