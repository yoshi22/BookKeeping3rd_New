# 2025-10-13 UI Refresh Visual Details

## 目的
Figmaのホーム画面デザイン（`docs/design/ホーム.png`）を基に、アプリ全体のビジュアルを刷新し、トンマナの統一とUIの見通しを改善する。

## デザイン変更ポイント
- **ブランドカラーの再定義**（`src/theme/colors.ts`）
  - プライマリ: ティール系 `#3FADBB` を中心にグラデーションを設定。
  - セカンダリ: コーラル系 `#E15A3D` をアクセントカラーに採用。
  - ニュートラル: ウォームグレー `#F7F3F0` 〜 `#212121` の階調で背景を統一。
  - 学習状態・カテゴリカラー・グラデーション・フォーカスカラーも新トーンへ更新。

- **ホームタブ**（`app/(tabs)/index.tsx`）
  - ヒーローカード導入（アイコン背景 + タイトル + 説明 + CTA）。
  - クイックアクションカード3種（学習／復習／統計）向けに自作の `QuickActionIcon` コンポーネント（幾何学図形ベース）を追加し、Figmaのシルエットに寄せた独自モチーフへ変更。
  - 余白・影（Shadow / Elevation）をFigmaデザインに合わせて調整。

- **学習タブ**（`app/(tabs)/learning/index.tsx`）
  - カテゴリカードの絵文字を `AppIcon` ベクターへ置き換え、色をカテゴリカラーに合わせて整理。
  - カードレイアウトを角丸・影・余白で刷新し、情報の階層化を明確化。

- **復習タブ**（`app/(tabs)/review/index.tsx`）
  - ヘッダーにタイトルアイコンを追加し、サブタイトルと合わせて視覚階層を構築。
  - 復習／統計タブをアイコン＋ラベルのボタン化、CTAカードをアイコン付きカードに変更。
  - 分野別弱点カードや統計カードの配色・影・グラフ表示を新トーンに揃え、情報量を整理。

- **タブバー**（`app/(tabs)/_layout.tsx`）
  - 背景色・影を再調整し、アクティブタブにティールのトーンを使用。
  - 全タブアイコンを `AppIcon`（home / learning / stats / settings）に統一。

- その他画面（設定タブなど）の追加整備や、lintで発生している既存警告の整理。
