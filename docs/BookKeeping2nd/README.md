# 簿記2級 開発ドキュメント（Draft）

本ディレクトリは、現行アプリ（簿記3級）の機能・UIをベースに簿記2級対応へ拡張するための設計ドラフトを集約します。まずは問題類型と必要問題数のドラフトから合意形成を行い、その後に情報設計・実装計画・制作フローへ展開します。

## ドキュメント一覧
- 問題類型と必要問題数（ドラフト）: [problem-design-draft.md](./problem-design-draft.md)

## 既存アプリからの再利用前提
- 画面遷移・模試フロー・復習（SRS）: 既存のタブ構成・復習タブを継承
- 問題データ構造: 3級の `src/data/*` で用いているスキーマに準拠し、2級拡張カテゴリを追加
- 分類・タグ: 2級の単元（商業簿記/工業簿記）毎に細分化し、復習サービスのフィルタリングと連動

## 次のステップ（合意後）
1. 情報設計: データスキーマ（カテゴリID・難易度・タグ・試験セクション）
2. 制作フロー: 問題制作 -> 検証 -> 解説レビュー -> アプリ組み込み
3. 実装: 2級タブ/フィルタ/模試セット生成（既存UIに追従）
4. QA: ユニット（解答判定）/E2E（模試完走・復習投入）

> 注意: 本ドラフトは一般的な出題傾向・学習時間の相場を前提とした暫定案です。最終的な配点・仕様は公式情報（商工会議所）を確認のうえ微調整します。
