# アルファテスト前品質検証計画 - 2025-08-24

## 検証概要

**目的**: アルファテストリリース前の品質保証  
**方式**: リスクベース段階的手動テスト  
**対象**: 全65問（Phase 1: 15問 + Phase 2: 30問 + Phase 3: 20問）  
**判定基準**: 全問題でエラーなし（100%成功）

## 実施方針

### 検証レベル

1. **UI動作確認**: 画面遷移・要素表示の正常性
2. **データ入力検証**: 正答データの正確な入力可能性
3. **判定ロジック確認**: 送信・採点・結果表示の正常性
4. **ナビゲーション**: 問題間移動・画面復帰の正常性

### 使用ツール

- iOSシミュレーター（iPhone 16）
- testIDベースの要素アクセス
- スクリーンショット（エラー時のみ）

## 実施手順

### 事前準備

#### 1. 環境構築

```bash
# Expoサーバー確認
BashOutput --bash_id bash_1

# シミュレーター一覧取得
mcp__xcodebuild__list_sims

# シミュレーター起動
mcp__xcodebuild__boot_sim --simulatorUuid "UUID"
mcp__xcodebuild__open_sim

# アプリビルド・起動
mcp__xcodebuild__build_run_sim --projectPath "/path/to/project" --scheme "BookKeeping3rd" --simulatorName "iPhone 16"
```

#### 2. テスト開始前確認

- [ ] シミュレーター正常起動
- [ ] アプリ正常起動
- [ ] 学習画面アクセス可能
- [ ] testID動作確認

### テスト実行手順（各問題）

#### Step 1: 問題選択

```bash
mcp__xcodebuild__tap --simulatorUuid "UUID" --testID "learning-all-questions-button"
```

#### Step 2: 問題詳細確認

- 問題文表示
- フォーム要素表示
- UI要素の配置

#### Step 3: 正答データ入力

```bash
# 例：仕訳問題
mcp__xcodebuild__tap --simulatorUuid "UUID" --testID "debit-account-dropdown-0"
# 勘定科目選択
mcp__xcodebuild__tap --simulatorUuid "UUID" --testID "debit-amount-input-0"
# 金額入力
mcp__xcodebuild__type_text --simulatorUuid "UUID" --text "10000"
```

#### Step 4: 解答送信・判定確認

```bash
mcp__xcodebuild__tap --simulatorUuid "UUID" --testID "submit-answer-button"
```

#### Step 5: 結果記録

- 成功/失敗の記録
- エラー内容（あれば）
- スクリーンショット（エラー時のみ）

### エラー対応

1. **即座停止**: エラー発生時は該当問題で停止
2. **詳細記録**: エラー内容・画面状況を詳細記録
3. **スクリーンショット**: 証跡として画面キャプチャ
4. **継続判定**: 致命的エラーでなければ次問題に進行

## 判定基準

### 成功条件

- **Phase 1**: 15/15問成功（100%）
- **Phase 2**: 30/30問成功（100%）
- **Phase 3**: 20/20問成功（100%）
- **合計**: 65/65問成功（100%）

### エラー分類

- **Lv1 - 致命的**: アプリクラッシュ・画面フリーズ
- **Lv2 - 重要**: 正答入力不可・判定エラー
- **Lv3 - 軽微**: UI表示崩れ・レスポンス遅延

### リリース判定

- **Go**: Lv1,Lv2エラー0件、Lv3エラー2件以内
- **No-Go**: Lv1,Lv2エラー1件以上、またはLv3エラー3件以上
