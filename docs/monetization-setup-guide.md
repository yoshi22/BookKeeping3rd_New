## 1. AdMob設定

### 1.1 AdMobアカウント作成・ログイン

1. https://admob.google.com/ にアクセス
2. Googleアカウントでログイン
3. 初回の場合はAdMobアカウントを作成

### 1.2 iOSアプリの登録

```
画面遷移:
ホーム → サイドメニュー「アプリ」→「アプリを追加」
```

1. **「アプリを追加」** をクリック
2. **プラットフォーム**: 「iOS」を選択
3. **「アプリはApp Storeに公開されていますか？」**:
   - 公開済み: 「はい」→ アプリを検索して選択
   - 未公開: 「いいえ」→ アプリ名を手動入力
4. **アプリ名**: `簿記3級問題集` を入力
5. **「アプリを追加」** をクリック
6. **App ID** が表示される（例: `ca-app-pub-1234567890123456~1234567890`）
   - **このIDをメモ** → `app.json`に設定

### 1.3 iOS広告ユニット作成

```
画面遷移:
アプリ → [簿記3級問題集 iOS] → サイドメニュー「広告ユニット」→「広告ユニットを追加」
```

#### バナー広告ユニット

1. **「広告ユニットを追加」** をクリック
2. **広告フォーマット**: 「バナー」を選択
3. **広告ユニット名**: `banner_ios` を入力
4. **「広告ユニットを作成」** をクリック
5. **広告ユニットID** が表示される（例: `ca-app-pub-1234567890123456/1234567890`）
   - **このIDをメモ**

#### インタースティシャル広告ユニット

1. **「広告ユニットを追加」** をクリック
2. **広告フォーマット**: 「インタースティシャル」を選択
3. **広告ユニット名**: `interstitial_ios` を入力
4. **「広告ユニットを作成」** をクリック
5. **広告ユニットID** をメモ

### 1.4 Androidアプリの登録

```
画面遷移:
ホーム → サイドメニュー「アプリ」→「アプリを追加」
```

1. **「アプリを追加」** をクリック
2. **プラットフォーム**: 「Android」を選択
3. **「アプリはGoogle Playに公開されていますか？」**:
   - 公開済み: 「はい」→ パッケージ名で検索
   - 未公開: 「いいえ」→ アプリ名を手動入力
4. **アプリ名**: `簿記3級問題集` を入力
5. **「アプリを追加」** をクリック
6. **App ID** をメモ

### 1.5 Android広告ユニット作成

iOS と同様の手順で以下を作成:

- バナー広告ユニット: `banner_android`
- インタースティシャル広告ユニット: `interstitial_android`

### 1.6 取得したIDの一覧

| 項目                               | iOS                      | Android                  |
| ---------------------------------- | ------------------------ | ------------------------ |
| App ID                             | `ca-app-pub-XXXXX~XXXXX` | `ca-app-pub-XXXXX~XXXXX` |
| バナー広告ユニットID               | `ca-app-pub-XXXXX/XXXXX` | `ca-app-pub-XXXXX/XXXXX` |
| インタースティシャル広告ユニットID | `ca-app-pub-XXXXX/XXXXX` | `ca-app-pub-XXXXX/XXXXX` |

## 2. iOS IAP設定（App Store Connect）

### 2.1 App Store Connectにログイン

1. https://appstoreconnect.apple.com/ にアクセス
2. Apple IDでログイン

### 2.2 App内課金の作成

```
画面遷移:
マイApp → [簿記3級問題集] → サイドメニュー「機能」→「App内課金」
```

1. **「App内課金」** タブをクリック
2. **「(+)」ボタン** をクリック（App内課金を管理の横）

### 2.3 App内課金タイプの選択

1. **タイプ**: 「非消耗型」を選択
   - 非消耗型 = 一度購入すれば永続的に有効（広告削除に最適）
2. **「作成」** をクリック

### 2.4 App内課金の詳細設定

#### 基本情報

| 項目   | 入力値       |
| ------ | ------------ |
| 参照名 | `広告削除`   |
| 製品ID | `remove_ads` |

**重要**: 製品IDは一度設定すると変更できません。コード内の `IAP_PRODUCTS.REMOVE_ADS` と一致させてください。

#### 価格設定

```
画面遷移:
App内課金詳細 → 「価格表」セクション → 「App内課金の価格を追加」
```

1. **「App内課金の価格を追加」** をクリック
2. **基準となる国または地域**: 「日本」を選択
3. **価格**: 「¥500」（Tier 5相当）を選択
4. **「次へ」** → **「作成」**

#### ローカライゼーション（日本語）

```
画面遷移:
App内課金詳細 → 「App Storeのローカリゼーション」セクション → 「(+)」
```

1. **「(+)」** をクリック
2. **言語**: 「日本語」を選択
3. 以下を入力:

| 項目   | 入力値                                                                               |
| ------ | ------------------------------------------------------------------------------------ |
| 表示名 | `広告を削除`                                                                         |
| 説明   | `すべての広告を非表示にして、集中して学習できます。一度購入すれば永続的に有効です。` |

4. **「追加」** をクリック

#### 審査情報

```
画面遷移:
App内課金詳細 → 「審査情報」セクション → 「編集」
```

1. **スクリーンショット**:
   - アプリ内の広告削除購入画面のスクリーンショットをアップロード
   - 設定画面の「広告を削除」ボタンが見える状態を撮影

2. **審査メモ**（任意）:
   ```
   この購入により、アプリ内のすべてのバナー広告とインタースティシャル広告が非表示になります。
   設定画面の「広告を削除」ボタンから購入できます。
   ```

### 2.5 App内課金の有効化

1. すべての必須項目を入力後、**「保存」** をクリック
2. ステータスが「送信準備完了」になることを確認

**注意**: App内課金はアプリの次回審査時に一緒に審査されます。

## 3. Android IAP設定（Google Play Console）

### 3.1 Google Play Consoleにログイン

1. https://play.google.com/console/ にアクセス
2. Googleアカウントでログイン

### 3.2 アプリ内アイテムの作成

```
画面遷移:
すべてのアプリ → [簿記3級問題集] → サイドメニュー「収益化」→「商品」→「アプリ内アイテム」
```

1. **「収益化」** セクションを展開
2. **「商品」** → **「アプリ内アイテム」** をクリック
3. **「商品を作成」** をクリック

### 3.3 アプリ内アイテムの詳細設定

#### 基本情報

| 項目   | 入力値                                                                               |
| ------ | ------------------------------------------------------------------------------------ |
| 商品ID | `remove_ads`                                                                         |
| 名前   | `広告を削除`                                                                         |
| 説明   | `すべての広告を非表示にして、集中して学習できます。一度購入すれば永続的に有効です。` |

**重要**: 商品IDは一度設定すると変更できません。

#### 価格設定

1. **「価格を設定」** または **「価格を管理」** をクリック
2. **デフォルトの価格**:
   - 国: 「日本」
   - 価格: `¥500` を入力
3. **「価格を適用」** をクリック
4. 他の国の価格は自動換算されます（必要に応じて調整）

### 3.4 アプリ内アイテムの有効化

1. すべての項目を入力後、**「保存」** をクリック
2. **「有効化」** をクリック
3. ステータスが「有効」になることを確認

## 4. テスト環境設定

### 4.1 iOS Sandboxテスター設定

```
画面遷移:
App Store Connect → ユーザーとアクセス → Sandbox → テスター
```

#### Sandboxテスターの追加

1. https://appstoreconnect.apple.com/ にログイン
2. ホーム画面で **「ユーザーとアクセス」** をクリック
3. 左サイドメニューで **「Sandbox」** セクションを展開
4. **「テスター」** をクリック
5. **「(+)」** ボタンをクリック

#### テスター情報の入力

| 項目           | 入力値                                                 |
| -------------- | ------------------------------------------------------ |
| 名             | テスト用の名前                                         |
| 姓             | テスト用の姓                                           |
| メールアドレス | **実際に使用していないメールアドレス**（新規作成推奨） |
| パスワード     | 任意のパスワード                                       |
| 秘密の質問     | 任意                                                   |
| 国または地域   | 日本                                                   |

**注意**:

- Sandboxテスターのメールアドレスは、実際のApple IDとは別のものを使用
- このアカウントはテスト購入専用

#### 実機でのテスト手順

1. iPhoneの **設定** アプリを開く
2. **App Store** → 一番下までスクロール → **サインアウト**
3. **サインインしない** 状態でアプリを起動
4. 購入時にSandboxテスターのApple IDでサインイン

### 4.2 Androidライセンステスター設定

```
画面遷移:
Google Play Console → 設定 → ライセンステスト
```

#### ライセンステスターの追加

1. https://play.google.com/console/ にログイン
2. 左サイドメニューで **「設定」** をクリック
3. **「ライセンステスト」** をクリック
4. **「Gmailアカウントをカンマ区切りで追加」** 欄にテスターのGmailを入力
5. **「変更を保存」** をクリック

#### ライセンス応答の設定

| 設定項目       | 推奨値     |
| -------------- | ---------- |
| ライセンス応答 | `LICENSED` |

**注意**: `LICENSED` に設定すると、テスターは実際に課金されずにテスト購入ができます。

#### テスト用内部テストトラックの設定（推奨）

```
画面遷移:
Google Play Console → [アプリ] → テスト → 内部テスト
```

1. **「テスト」** → **「内部テスト」** をクリック
2. **「テスターを管理」** → **「メーリングリストを作成」**
3. テスターのGmailアドレスを追加
4. テスト版APKをアップロード
5. テスターに招待リンクを送信

## 5. コード更新

### 5.1 AdMob ID の更新

**ファイル**: `src/config/monetization.ts`

```typescript
// 本番用広告ユニットID（AdMobコンソールで取得したIDに置き換え）
const PROD_AD_UNITS = {
  ios: {
    banner: "ca-app-pub-XXXXX/XXXXX", // ← 取得したiOSバナーID
    interstitial: "ca-app-pub-XXXXX/XXXXX", // ← 取得したiOSインタースティシャルID
  },
  android: {
    banner: "ca-app-pub-XXXXX/XXXXX", // ← 取得したAndroidバナーID
    interstitial: "ca-app-pub-XXXXX/XXXXX", // ← 取得したAndroidインタースティシャルID
  },
};
```

### 5.2 AdMob App ID の更新

**ファイル**: `app.json`

```json
{
  "expo": {
    "plugins": [
      [
        "react-native-google-mobile-ads",
        {
          "androidAppId": "ca-app-pub-XXXXX~XXXXX", // ← 取得したAndroid App ID
          "iosAppId": "ca-app-pub-XXXXX~XXXXX" // ← 取得したiOS App ID
        }
      ]
    ]
  }
}
```

### 5.3 更新後の確認

```bash
# 開発ビルドを再作成（ネイティブ設定が変更されるため必須）
npx expo prebuild --clean
npx expo run:ios
# または
npx expo run:android
```

## トラブルシューティング

### AdMob広告が表示されない

1. **App IDが正しいか確認**: `app.json` の設定を再確認
2. **広告ユニットIDが正しいか確認**: `monetization.ts` を再確認
3. **prebuildを実行したか**: ネイティブ設定変更後は `npx expo prebuild --clean` が必要
4. **新規広告ユニットの場合**: 作成後24時間程度で配信開始されることがあります

### IAP購入ができない

**iOS**:

- Sandboxテスターでサインインしているか確認
- 実機でテストしているか確認（シミュレーターでは動作しません）

**Android**:

- ライセンステスターに追加されているか確認
- 内部テストトラックに参加しているか確認
- 商品が「有効」状態か確認

### テスト購入で課金された

- iOS: Sandboxテスターアカウントを使用していれば課金されません
- Android: ライセンス応答が `LICENSED` になっているか確認
