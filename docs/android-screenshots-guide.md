# Android スクリーンショット準備ガイド

## 📸 Google Play用スクリーンショット作成手順

このガイドでは、簿記3級「復習マスター」AlphaのGoogle Play掲載用スクリーンショットを作成する手順を説明します。

---

## 📋 要件

### スクリーンショット仕様

- **最小枚数**: 2枚
- **推奨枚数**: 4-8枚
- **サイズ**: 縦長（1080x1920 または 1440x2560）
- **形式**: PNG または JPG
- **アスペクト比**: 16:9

### 推奨する画面キャプチャ

1. **ホーム画面** - アプリの第一印象
2. **学習画面（問題一覧）** - カテゴリ別学習機能
3. **問題解答画面（仕訳入力）** - CBT形式の入力UI
4. **復習画面** - 優先復習機能
5. **統計画面** - 学習進捗の可視化

---

## 方法1: Androidエミュレーターで撮影（推奨）

### ステップ1: エミュレーター起動

```bash
# プロジェクトディレクトリで実行
cd /Users/muroiyousuke/Projects/BookKeeping3rd

# Androidエミュレーター起動
npm run android
```

### ステップ2: 各画面に遷移してスクリーンショット撮影

#### エミュレーターでの撮影方法

1. エミュレーター右側のツールバー（縦に並んだアイコン）
2. **カメラアイコン**をクリック
3. スクリーンショットが自動保存される

**保存場所（デフォルト）**:

```
~/Desktop/Screenshot_YYYYMMDD-HHMMSS.png
```

### ステップ3: 推奨撮影順序

#### 1. ホーム画面

- アプリ起動直後の画面
- 学習継続日数、統計サマリーが表示されている状態

#### 2. 学習画面

- 下部タブから「学習」をタップ
- カテゴリ一覧が表示されている状態

#### 3. 問題解答画面（仕訳問題）

- 「全問題を順次進行」または任意のカテゴリを選択
- 仕訳入力フォームが表示されている状態
- 可能であれば一部入力済みの状態

#### 4. 復習画面

- 下部タブから「復習」をタップ
- 優先復習ボタンが表示されている状態
- （事前に何問か間違えておく必要あり）

#### 5. 統計画面

- 復習タブの「統計」タブをタップ
- 学習進捗グラフが表示されている状態

## 方法2: 実機で撮影（オプション）

### Android実機での撮影方法

1. **電源ボタン + 音量下ボタン**を同時押し
2. スクリーンショットが撮影される
3. 「ギャラリー」または「フォト」アプリで確認

**保存場所**:

```
/sdcard/Pictures/Screenshots/
```

### PCへ転送（USBケーブル）

```bash
# Android Debug Bridge (ADB) で転送
adb pull /sdcard/Pictures/Screenshots/ ~/Desktop/screenshots/
```

## 方法3: スクリーンショット編集・リサイズ

### サイズ調整が必要な場合

Google Playの要件（1080x1920）に合わせてリサイズ：

#### ImageMagickを使用（推奨）

```bash
# ImageMagickインストール（未インストールの場合）
brew install imagemagick

# リサイズコマンド
convert input.png -resize 1080x1920 output.png

# バッチ処理（複数ファイル）
for file in screenshot*.png; do
  convert "$file" -resize 1080x1920 "resized_$file"
done
```

#### オンラインツール（簡単）

- [Squoosh](https://squoosh.app/) - Googleの画像最適化ツール
- [TinyPNG](https://tinypng.com/) - PNG圧縮・最適化

## スクリーンショット品質向上のコツ

### テストデータの準備

統計やグラフを見やすくするため、事前にテストデータを作成：

```bash
# テストデータ作成スクリプト実行
node scripts/testing/test-database.js
```

### 見栄えの良い画面を作る

1. **ホーム画面**: 学習継続日数が1日以上表示されている
2. **学習画面**: カテゴリごとの問題数が表示されている
3. **問題画面**: 入力フォームに一部データが入っている（空白より見やすい）
4. **復習画面**: 復習対象問題がある状態（事前に何問か間違える）
5. **統計画面**: 学習履歴がある状態（グラフが表示される）

### ダークモード対応（オプション）

両方のテーマでスクリーンショットを撮影すると、ユーザーに選択肢を提示できます：

1. アプリ内の設定からテーマを切り替え
2. ライトモード・ダークモードそれぞれでスクリーンショット撮影

## スクリーンショットチェックリスト

アップロード前に確認：

- [ ] サイズ要件を満たしている（1080x1920 または 1440x2560）
- [ ] 縦長（ポートレート）モードで撮影
- [ ] 画像が鮮明（ぼやけていない）
- [ ] UI要素が見やすい（文字が小さすぎない）
- [ ] 個人情報が写り込んでいない
- [ ] 最低2枚、推奨4-8枚準備
- [ ] PNG または JPG形式

## Google Play Consoleへのアップロード

### アップロード手順

1. Google Play Console → アプリ選択
2. 「ストアでの表示」→「メインのストア掲載情報」
3. 「スクリーンショット」セクション
4. 「携帯電話」タブを選択
5. 画像をドラッグ＆ドロップまたは「ファイルを選択」

### アップロード後の確認

- プレビューで画像が正しく表示されているか
- 画像の順序が適切か（最も魅力的な画像を先頭に）
- 保存を忘れずに！

## 🎨 デザインTips（オプション）

### より魅力的なスクリーンショットを作成

Google Playのストア掲載画像として、以下のようなデザイン要素を追加することも可能：

1. **テキストオーバーレイ**

## トラブルシューティング

### Q1: スクリーンショットサイズが要件に合わない

**A**: ImageMagickでリサイズ

```bash
convert input.png -resize 1080x1920 -background white -gravity center -extent 1080x1920 output.png
```

### Q2: エミュレーターのスクリーンショットが撮れない

**A**: 以下の方法を試す：

1. エミュレーターのカメラアイコン
2. `Ctrl + S`（Windows）または `Cmd + S`（Mac）
3. Android Studio → Tools → Device Manager → スクリーンショット

### Q3: ファイルサイズが大きすぎる

**A**: PNG圧縮ツールを使用

```bash
# pngquantでファイルサイズ削減
pngquant --quality=65-80 input.png -o output.png
```
