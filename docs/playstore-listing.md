## 詳細な説明（4000文字以内）

```
【簿記3級「確実復習」とは】
間違えた問題を繰り返し学習することで、苦手分野を克服する復習特化型の簿記3級学習アプリです。

【主な機能】
✅ 302問の厳選問題（仕訳250問・帳簿40問・試算表12問）
✅ 間違えた問題を自動的に優先表示
✅ カテゴリ別の弱点分析
✅ 学習進捗の可視化
✅ 学習機能は無料で利用可能
✅ 学習データは端末保存
✅ プライバシー重視（データ収集なし）

【こんな方におすすめ】
・簿記3級試験の受験を控えている方
・苦手分野を効率的に克服したい方
・スキマ時間で効率的に復習したい方
・繰り返し学習で定着させたい方

【アプリの特徴】
このアプリは「間違えた問題ほど優先的に復習する」という間隔反復学習の原理に基づいています。一度不正解だった問題は自動的に復習リストに追加され、連続2回正解するまで優先的に出題されます。

【試験対策に最適】
日商簿記3級の本試験形式（CBT）に対応した問題構成で、実践的な学習が可能です。
・第1問対策：仕訳問題 250問（45点分）
・第2問対策：帳簿問題 40問（20点分）
・第3問対策：試算表問題 12問（35点分）

【料金と広告について】
学習機能は無料でご利用いただけます。無料利用時には広告が表示されます。
広告非表示は、任意の買い切りアプリ内購入「広告を非表示」で利用できます。

【プライバシー保護】
学習データはデバイス内に保存され、学習履歴や個人情報を自社サーバーへ送信することはありません。広告配信時やアプリ内購入手続き時には、各プラットフォームまたは広告配信事業者との通信が発生します。
```
