# 手動検証チェックリスト - 302問完全検証

## 検証概要

プログラム検証では確認できないUI要素の動作を最小限の代表問題で検証

**検証対象問題（5問）:**

1. Q_J_001 - 基本仕訳（現金取引）
2. Q_J_007 - 複合仕訳（複数エントリ）
3. Q_L_001 - 帳簿問題
4. Q_T_001 - 試算表問題
5. Q_J_012 - 複雑な仕訳問題

---

## Phase 1: 基本動作確認（testID使用）

### 学習画面へのアクセス

- [ ] `learning-all-questions-button` で学習開始
- [ ] 問題リストが表示される
- [ ] 最初の問題（Q_J_001）にアクセス可能

### 基本仕訳問題（Q_J_001）

- [ ] 問題文が正しく表示
- [ ] 借方勘定科目ドロップダウンがタップ可能
- [ ] 貸方勘定科目ドロップダウンがタップ可能
- [ ] 金額入力フィールドがタップ可能
- [ ] 勘定科目選択肢が十分（現金、商品等）
- [ ] `submit-answer-button` で解答送信
- [ ] 正答時に適切なフィードバック表示

---

## Phase 2: 複合問題検証（testID使用）

- [ ] 各行の金額入力が独立動作

- [ ] 解答送信・判定が正常
